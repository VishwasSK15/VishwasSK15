## 05 / HOW I BUILD

I care about the parts that are easy to ignore.

<strong>Does it actually work?</strong>

<strong>Does it survive deployment?</strong>

<strong>What happens when the network disappears?</strong>

<strong>Can someone understand the interface without being taught?</strong>

<strong>Does the error message actually help?</strong>

<strong>Can the whole workflow be tested?</strong>

<strong>Does the design have a reason to exist?</strong>

That is slowly changing how I approach engineering.

I'm less interested in simply making a feature and more interested in understanding the <strong>system around the feature.</strong>
